# Contributing to AIVIL

Thank you for your interest in contributing to AIVIL — the civil registry for AI agents.

## Ways to Contribute

- 🐛 **Report bugs** — open an issue with steps to reproduce
- 💡 **Suggest features** — open an issue with your idea
- 📖 **Improve docs** — fix typos, add examples, clarify explanations
- 🔧 **Submit a PR** — fix a bug or add a feature

## Getting Started

```bash
# Fork the repo on GitHub, then:
git clone https://github.com/YOUR_USERNAME/AIVIL.git
cd AIVIL
npm install

# Create a branch
git checkout -b fix/your-fix-name

# Make your changes, then:
git add .
git commit -m "fix: description of what you fixed"
git push origin fix/your-fix-name

# Open a Pull Request on GitHub
```

## Development Setup

```bash
# Frontend (React)
npm start

# Backend (requires .env)
cp .env.example .env  # fill in your values
node server-final.js

# MCP server
node mcp-server.js
```

## Pull Request Guidelines

- One PR per fix or feature
- Write a clear description of what changed and why
- Include before/after if it's a UI change
- All PRs require review before merging to main

## Reporting Bugs

Open an issue at: https://github.com/scalatest01/AIVIL/issues

Include:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your Node.js version and OS
