# AIVIL Roadmap

## ✅ v1.0.0 — Foundation (Shipped)
- [x] Agent identity — EC P-256 keypairs, DID documents, birth certificates
- [x] Policy engine — spending limits, domain restrictions, topic filtering
- [x] Audit trail — HMAC-signed, tamper-proof, immutable
- [x] REST API — full CRUD for agents, audits, policies
- [x] npm SDK — `aivil@2.2.0` with timeout, retry, fallback
- [x] Dashboard — live feed, agent management, security screen
- [x] MCP server — zero-code Claude integration
- [x] Rogue detection — trust scores, auto-suspend

## 🚧 v1.1.0 — Integrations (Next)
- [ ] LangGraph integration guide + template
- [ ] CrewAI integration guide + template
- [ ] AutoGen integration guide + template
- [ ] Python SDK improvements
- [ ] Webhooks UI in dashboard

## 📋 v1.2.0 — Enterprise
- [ ] Self-hosting option (Docker)
- [ ] SOC2 audit readiness documentation
- [ ] GDPR compliance documentation
- [ ] Team accounts (multiple developers per org)
- [ ] Custom jurisdiction support

## 🔮 v2.0.0 — Decentralized
- [ ] Optional on-chain anchoring for audit records
- [ ] IPFS storage for birth certificates
- [ ] Cross-registry agent verification
- [ ] Public agent reputation scores

## Ideas We're Considering
